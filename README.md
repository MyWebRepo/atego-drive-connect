# Atego Drive

Erstelle eine moderne, professionelle und kompakte Single-Page-Webseite für eine Stellenvermittlung von LKW-Fahrern in Deutschland.

Design

Orientiere dich optisch an meinem Referenz-Screenshot:

dunkles, hochwertiges Design

Hintergrundbild mit einem Mercedes-Benz Atego LKW

dunkles Overlay über dem Hintergrundbild, damit Texte gut lesbar sind

Akzentfarbe Orange

weiße Überschriften

graue/hellblaue Beschreibungstexte

moderne Cards mit dunklem Hintergrund und dünnem grauen Border

große, markante Überschriften

modernes Fahrer-/Logistik-Design

seriös und vertrauenswürdig

keine unnötigen Animationen

keine lange Landingpage

Die Seite soll auf Desktop möglichst auf einen Bildschirm bzw. maximal ungefähr 1–1,5 Bildschirmhöhen passen.

Layout

Erstelle direkt unter einer kurzen Hero-Überschrift einen großen Bereich mit zwei Spalten.

Linke Seite – Anforderungen

Überschrift:

TƏLƏBLƏR

Zeige die Anforderungen übersichtlich als Cards oder als Liste mit kleinen orangefarbenen Icons.

Anforderungen:

C1 və ya C kateqoriyası
Mercedes-Benz Atego üçün ən azı C1 (7,5 t), daha yaxşısı C/CE sürücülük vəsiqəsi lazımdır.

Sürücü kartı və Modul 95
Etibarlı sürücü kartı və BKrFQG üzrə təlim / Modul 95 olmalıdır.

İş təcrübəsi
Şəhər və ya regional daşımada sürücülük təcrübəsi üstünlükdür.

Alman dili
Müştərilərlə və şirkətlə ünsiyyət üçün minimum A2/B1 səviyyəsində alman dili.

Oben über den Anforderungen zusätzlich kompakt anzeigen:

Əmək haqqı: 2.700 € brutto-dan

İş vaxtı: B.e.–C., şəhərdaxili

Başlama: qısa müddətdə mümkündür

Diese drei Informationen können als kleine kompakte Info-Cards dargestellt werden.

Hero-Bereich

Oberhalb der beiden Spalten nur einen kleinen, kompakten Hero-Bereich verwenden.

Text:

klein in Orange:

VAKANSİYA · ALMANİYA · ŞƏHƏRDAXİLİ DAŞIMALAR

Große Überschrift:

MERCEDES ATEGO ÜÇÜN SÜRÜCÜ AXTARILIR

Beschreibung:

Sabit marşrut, nizamlı iş saatları və müasir avtomobillər. Tələblərə uyğunsansa, məlumatlarını doldur və müraciət et.

Keinen großen separaten CTA-Bereich unter dem Hero erstellen, weil das Formular direkt sichtbar sein soll.

Wichtig

Die Webseite darf NICHT wie meine bisherige Version sehr lang werden.

Die wichtigsten Inhalte sollen gleichzeitig sichtbar sein:

LEFT:
Anforderungen

RIGHT:
Bewerbungsformular

Desktop-Aufteilung ungefähr:

45 % Anforderungen | 55 % Formular

Verwende eine maximale Content-Breite von ungefähr 1200–1400 px.

Auf mobilen Geräten:

Überschrift

Anforderungen

Bewerbungsformular

untereinander anzeigen.

Das Hintergrundbild des Mercedes Atego soll hauptsächlich im oberen Bereich sichtbar sein und durch einen dunklen Verlauf elegant in den normalen dunklen Seitenhintergrund übergehen.

Behalte den visuellen Stil meines Referenzdesigns bei, aber reduziere die Seite deutlich und entferne separate Bereiche wie „Proses“, lange Erklärungen und doppelte Call-to-Action-Sektionen.
